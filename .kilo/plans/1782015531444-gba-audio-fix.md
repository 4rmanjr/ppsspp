# GBA Audio Quality Fix — Implementation Plan

**Goal:** Fix "kasar & cempreng" GBA audio in PPSSPP fork. Zero changes to PSP audio path.

**Root cause:** DC blocking filter in `EmuCore/GBACore.cpp` is mathematically broken — capacitor only self-decays, never tracks actual DC offset from mGBA's SOUNDBIAS.

## Tasks

### Task 1: Fix DC Blocking Filter

**File:** `EmuCore/GBACore.cpp:464-480`

Replace the broken filter with proper EMA tracker:

```cpp
// dcCapL_ += (input - dcCapL_) * alpha  (tracks DC offset)
dcCapL_ += (left - dcCapL_) * 0.004f;
dcCapR_ += (right - dcCapR_) * 0.004f;

float outL = left - dcCapL_;
float outR = right - dcCapR_;
```

Remove the old `float outL = left - dcCapL_; ... dcCapL_ = (left - outL) * 0.996f;` pattern entirely.

### Task 2: Fix ClearAudio Stale Samples

**File:** `EmuCore/GBACore.cpp:435-444`

Add `mAudioBufferClear(resampleDest_)` to prevent stale sample carryover after fast-forward frame skip:

```cpp
void GBACore::ClearAudio() {
    struct mAudioBuffer *src = core_->getAudioBuffer(core_);
    if (src) {
        mAudioBufferClear(src);
    }
    // Clear resampler dest to prevent stale samples after frame skip
    mAudioBufferClear(static_cast<struct mAudioBuffer*>(resampleDest_));
    audioStereoPairs_ = 0;
}
```

### Task 3: Build Verification

Run both configurations:
- `cmake -DPPSSPP_MULTICORE=ON .. && make -j$(nproc)` — must succeed
- `cmake -DPPSSPP_MULTICORE=OFF .. && make -j$(nproc)` — must succeed (no custom code leaks)
